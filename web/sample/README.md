# sample · 마이크 대신 쓸 녹음

마이크 없이 돌려 보거나, 같은 목소리로 규칙을 여러 번 비교할 때 씁니다.

```bash
./start.sh --sim
```

녹음은 저장소에 올라가지 않습니다. 설치할 때 받고, 따로 받으려면 `python fetch_sample.py` 입니다.
받을 때 출처와 조건이 `credits.md` 에 적힙니다.

- `목소리.flac` 한 남성이 네덜란드어로 22초 동안 말합니다. 빠르기·크기·높낮이·멈춤을 시험하는 데는
  말의 뜻이 필요 없어 이것을 골랐습니다. 위키미디어 공용, CC0.

자기 녹음으로 바꾸려면 같은 이름으로 덮어쓰면 됩니다(wav, mp3, flac 모두 됩니다. 이름의 확장자는
`web/app.js` 맨 위 `SAMPLE` 에서 바꿉니다).
