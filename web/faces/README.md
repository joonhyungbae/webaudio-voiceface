# faces · 얼굴 은행

여기에 그림을 넣으면 선으로 그린 기본 얼굴 대신 이 그림들을 조합합니다.

1. 얼굴 그림을 `01.png`, `02.png` … 처럼 넣습니다. **크기가 같고, 정면이고, 눈·코·입 높이가 대략 맞아야**
   띠가 자연스럽게 이어집니다. 세로 3:4(예: 600×800)를 권합니다.
2. 같은 폴더에 `faces.json` 을 만듭니다.

```json
[
  { "src": "01.png", "mouth": [0.5, 0.71, 0.18] },
  { "src": "02.png", "mouth": [0.5, 0.70, 0.16] }
]
```

`mouth` 는 입 가운데의 가로 위치, 세로 위치, 입 너비입니다(그림 크기에 대한 비율). 입을 벌릴 자리를 정합니다.
순서가 중요합니다. `web/rule.js` 는 「앞쪽 얼굴, 뒤쪽 얼굴」로 고르므로, 목소리가 낮을 때 나오길 바라는
얼굴을 앞에 둡니다. 띠의 높이와 폭은 `web/settings.js` 의 `BANDS` 에서 그림에 맞춥니다.

`faces.json` 이 없으면 이 폴더는 비어 있어도 됩니다.
