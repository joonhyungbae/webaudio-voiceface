# faces · 얼굴 은행

목소리가 고를 수 있는 얼굴들입니다. 지금 들어 있는 `01.jpg`~`10.jpg` 는 예제로 만든 가상 인물 사진입니다
(`tools/make_faces.py`, APIFrame 의 FLUX.2 Pro). 실존 인물이 아닙니다. 작가의 얼굴로 바꿔 쓰면 됩니다.

같은 방식으로 자기 얼굴 은행을 만들려면 `tools/make_faces.py` 의 `PEOPLE` 목록을 고치고 돌립니다.
수업에서 쓴 APIFrame 키를 그대로 쓰고(장당 4크레딧 안팎), 키는 저장소에 들어가지 않습니다.

## 말하는 영상

`NN.mp4` 는 같은 얼굴이 카메라를 보고 말하는 10초 영상입니다(`tools/make_videos.py`, APIFrame 의 Hailuo 02).
다시 듣기 때 입 부위를 이 영상에서 가져옵니다. 입이 여러 모양으로 열리고 닫히는 영상일수록 좋습니다.
`faces.json` 에 `"video": "NN.mp4"` 로 이어 둡니다. 영상이 없는 얼굴은 사진의 입을 움직여 대신합니다.
영상은 저장소에 올라가지 않고 설치할 때 받습니다. 직접 넣은 영상은 키프레임이 촘촘해야 준비가 빠릅니다
(`ffmpeg -i 원본.mp4 -an -c:v libx264 -crf 22 -g 4 -bf 0 NN.mp4`).

## 바꾸는 법

1. 사진을 이 폴더에 넣습니다. jpg, png 모두 됩니다.
2. `faces.json` 에 순서대로 적습니다.

```json
[
  { "src": "01.jpg" },
  { "src": "02.jpg" }
]
```

3. 브라우저를 새로 고침합니다. 얼굴마다 랜드마크를 찾느라 몇 초 걸립니다. 얼굴을 못 찾은 사진은
   조작 화면 상태 줄에 이름이 나오고 빠집니다.

## 잘 섞이는 사진

- **정면**이고 고개가 기울지 않았다.
- **입을 다물었다.** 입을 벌린 사진은 다시 듣기 때 입이 이상하게 열린다.
- **조명이 고르다.** 한쪽만 밝으면 섞인 얼굴에 얼룩이 생긴다. 은행의 사진끼리 조명이 비슷할수록 좋다.
- **배경이 단색**이다. 배경도 함께 섞인다.
- 크기와 위치는 달라도 된다. 두 눈을 기준으로 저절로 맞춘다.

AI 로 만든다면 이런 문장이 잘 맞았습니다:
「정면을 보는 머리와 어깨 사진, 무표정, 입을 다문, 밝은 회색 단색 배경, 그림자 없는 고른 정면 조명」.

## 순서

순서가 중요합니다. `web/rule.js` 는 「앞쪽 얼굴, 뒤쪽 얼굴」로 고릅니다. 지금 규칙은 낮은 목소리일수록
앞쪽 얼굴의 윤곽을 가져오므로, 그렇게 이어지길 바라는 차례로 늘어놓습니다.
