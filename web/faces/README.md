# faces · 얼굴 은행

목소리가 고를 수 있는 얼굴들입니다. 얼굴 하나가 **말하는 영상 하나**입니다. 영상 속 사람이 입을 가장 다문 순간이
그 얼굴의 기본 모습이 되고, 다시 듣기 때는 같은 영상에서 녹음에 맞는 입 모양 프레임을 골라 씁니다.

지금 들어 있는 10편은 예제로 만든 가상 인물입니다(실존 인물이 아닙니다). 설치할 때 받고 저장소에는 올라가지
않습니다. 작가의 얼굴로 바꿔 쓰면 됩니다.

| 파일 | 무엇 |
|---|---|
| `faces.json` | 쓸 영상 목록. 이 순서가 `web/rule.js` 의 「앞쪽 얼굴 → 뒤쪽 얼굴」이다 |
| `NN.mp4` | 말하는 영상 (10초 안팎) |
| `NN.lm.json` | 그 영상의 프레임마다 얼굴 랜드마크. 없으면 처음 켤 때 만들어 저장한다 |

## 바꾸는 법

1. 영상을 이 폴더에 넣고 `faces.json` 에 적습니다.

```json
[
  { "video": "01.mp4" },
  { "video": "02.mp4" }
]
```

2. `./start.sh` 로 켭니다. 새 영상이면 랜드마크를 재느라 처음 한 번은 영상마다 몇 초~1분 걸리고,
   `NN.lm.json` 으로 저장되어 다음부터는 바로 켜집니다.

## 잘 되는 영상

- **카메라를 정면으로 보고 말한다.** 고개를 크게 돌리거나 끄덕이지 않는다.
- **입이 여러 모양으로 열리고 닫힌다.** 크게 벌리기, 동그랗게 모으기, 다물고 쉬기가 다 있으면 좋다.
  다물고 쉬는 순간이 있어야 기본 모습이 자연스럽다.
- **조명이 고르고 배경이 단색이다.** 은행의 영상끼리 조명이 비슷할수록 섞인 얼굴에 얼룩이 없다.
- **키프레임이 촘촘하다.** 생성 모델의 영상은 키프레임이 처음에 하나뿐이라 준비가 느리다.
  `ffmpeg -i 원본.mp4 -an -c:v libx264 -crf 22 -g 4 -bf 0 NN.mp4` 로 다시 인코딩한다(`tools/make_videos.py` 는 저절로 한다).

## 예제는 이렇게 만들었다

1. `tools/make_faces.py` 로 정면 인물 사진 10장을 만들었다(APIFrame FLUX.2 Pro, `faces-src/`).
2. 그 사진을 첫 프레임 삼아 `tools/make_videos.py` 로 말하는 영상을 만들었다(APIFrame Hailuo 02, 편당 56크레딧).
   APIFrame 은 사진을 주소로 받으므로 사진을 인터넷에서 열리는 곳에 올리고 `--base` 로 그 주소를 준다.
   예제 사진은 이 저장소의 릴리스(faces-v1)에 있다.

수업에서 쓴 APIFrame 키를 그대로 쓰고, 키는 저장소에 들어가지 않습니다.
